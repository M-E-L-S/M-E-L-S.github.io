SUPPORTED DECODERS

支持的编码与密码

按用途展开查看；当前支持 24 类解码器。

不含空格的编码可用 /、|、换行或多个空格显式分词；单个空格仍用于编码分组。

未显式分词时，较长的连续英文解码结果会结合独立的完整英语词表和字符组合尝试自动分词，并优先保留较长的完整词。

编码（固定映射） 21 项

Base64

将二进制数据表示为 ASCII 字符。识别标准字母表、四字符分组与可选的 = 补位；解码结果必须是有效 UTF-8。

SGVsbG8gV29ybGQ= → Hello World

Base32

使用 A–Z 和 2–7 表示数据，常见于密钥和不区分大小写的文本传输；解码结果必须是有效 UTF-8。

JBSWY3DPEBLW64TMMQ====== → Hello World

Base58

使用 Bitcoin 字母表并排除容易混淆的 0、O、I、l。格式本身没有校验和，因此识别置信度低于 Base64。

JxF12TrwUP45BMd → Hello World

ASCII85

以五个可打印字符表示四个字节，支持 Adobe 的 <~ … ~> 包裹格式和零字节缩写 z。

<~87cURD]i,"Ebo7~> → Hello World

Base85（RFC 1924 / Git）

与 ASCII85 同属 85 进制编码，但使用不同的字母表；此项支持 RFC 1924 / Git 风格，解码结果必须是有效 UTF-8。

NM&qnZy;B1a%^M → Hello World

Base91

使用 91 字符字母表进行可变长度位打包，结果必须是有效 UTF-8。

fPNKd → test

Hex 十六进制

把每个字节写成两个十六进制数字，支持空格、冒号、逗号和连字符分隔；结果必须是有效 UTF-8。

48 65 6c 6c 6f → Hello

URL Percent-Encoding

识别 %xx 转义，并按照 URI 组件规则每次还原一层。搜索器会继续检测解码后的结果，因此可以自动处理多层百分号编码。

Hello%2520World → Hello%20World → Hello World

HTML Entity

支持十进制、十六进制数字实体，以及 amp、lt、gt、quot、apos。

&#72;&#105; → Hi

Binary 二进制字符码

每 8 位还原一个字节并按 UTF-8 解码。支持 0/1 或任意两种字符；字节组用单个空格分隔或连续书写，单词用 /、|、换行或多个空格分隔。

01001000 01101001 → Hi

Octal 八进制字符码

将空格或常见标点分隔的八进制字节还原为 UTF-8 文本。

110 145 154 154 157 → Hello

Decimal 十进制字符码

把 0–255 的十进制数字序列转换为字符，支持空白、冒号、逗号和连字符分隔。

72 105 → Hi

Unicode / Hex Escape

还原 JavaScript 和 JSON 文本中常见的 \uXXXX 与 \xXX 转义。

\u0048\u0069 → Hi

A1Z26

把 1–26 映射为 A–Z，支持空格及常见标点作为数字分隔符。

8 5 12 12 15 → HELLO

Bacon Cipher

每五个二元符号映射到 A–Z。支持 A/B 或任意两种符号；字母组用单个空格分隔或连续书写，单词用 /、|、换行或多个空格分隔。

aabbb aabaa ababb ababb abbba → HELLO

Morse 摩尔斯电码

支持拉丁字母与数字。点、划可用任意两种可打印符号表示；字母用单个空格分隔，单词用 /、|、换行或多个空格分隔。

.... .. / - .... . .-. . → HI THERE

Polybius 5×5

无密钥标准方阵，I/J 共用一格；每两个 1–5 数字表示行和列。

23 15 31 31 34 → HELLO

ADFGX（无换位）

使用标准 5×5 方阵将 A、D、F、G、X 字母对映射为文字，不处理需要密钥的列换位层。

DF AX FA FA FG → HELLO

Tap Code 敲击码

每两串敲击组成一个字母，点或其他重复字符均可，敲击串之间用单个空格分隔；单词用 /、|、换行或多个空格分隔，C/K 共用一格。

xx xxx x xxxxx → HE

Atbash

把拉丁字母表首尾互换：A↔Z、B↔Y。它是自反变换，应用两次会回到原文。

Svool → Hello

Reverse 文本反转

按 Unicode 字符顺序反转输入，用于常见的倒写谜题。它同样是自反变换。

dlroW olleH → Hello World
密码（需要密钥） 3 项

Caesar / ROT13

枚举 1–25 的全部字母移位，不改变非字母字符。ROT13 是位移 13 的自反特例。

Uryyb Jbeyq → Hello World

Rail Fence 栅栏密码

按标准之字形栅栏还原，枚举 2–10 栏；短文本不会枚举超过字符数一半的栏数。字母、数字、空白及各种可打印编码符号都作为字符参与重排；含数字或符号时逐级降低探测置信度。

WECRLTEERDSOEEFEAOCAIVDEN → WEAREDISCOVEREDFLEEATONCE（3 栏）

Keyboard Shift 键盘移位

按美式 QWERTY 键盘的行列位置，枚举左、右、上、下位移 1 或 2 个键；上下位移按相同列序号对应。保留字母大小写；越过键盘边界的方案不作为候选。

Jr;;p → Hello（左移 1 键）；Asdfgh → Qwerty（上移 1 行）
特殊领域 1 项

ACG Name

使用 Bangumi Archive 中具有罗马字或英文名、简体中文名的角色。开启后才加载角色词库；完整姓名参与自动分词，单独姓或名至少三个字母且使用较低权重。结果中出现可能的姓名时，会显示对应的 Bangumi 页面；重名和姓名片段只显示罗马音。
