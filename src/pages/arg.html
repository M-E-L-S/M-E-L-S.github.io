接受的输入格式
  • 1–64 个英文字母，如 LEMON；完整方阵可用 25 个不重复字母（I/J 合并）表示。
  • 两段或三段英文字母，用 / 分隔，如 SIMPLE / EASY 或 ONE / TWO / THREE；每段 1–64 个字母。
  • 两个整数 a, b：a 需要与26互质，b 为 0–25，如 5, 8。
  • 1 到 n 的数字排列（2≤n≤32），用空格或逗号分隔，如 3 1 4 2。
  • 2×2 或 3×3 整数矩阵，行用分号分隔，列用空格或逗号分隔，如 3 3; 2 5；元素为 0–25，矩阵须模 26 可逆。

最大深度限定连续解码层数；节点预算按取出的文本状态计数。

⚠ 并行模式会使用 CPU 多线程同时计算。Worker 越多，CPU 和内存占用越高，设备可能发热或出现卡顿。

输入文本后开始分析；所有计算都在此设备完成。不会上传云端。目前支持解密的方法详见标题上方的”支持的编码与密码“页面。

SUPPORTED DECODERS

支持的编码与密码

编码（固定映射） 21 项

Base64

用 64 种字符表示二进制数据，常见于邮件附件和网页中的嵌入资源。

SGVsbG8gV29ybGQ= → Hello World

Base32

用 32 种字符表示二进制数据，字母与数字的组合便于抄写和传递。

JBSWY3DPEBLW64TMMQ====== → Hello World

Base58

一种常见于加密货币地址的编码，通过去掉外形相近的字符减少抄写混淆。

JxF12TrwUP45BMd → Hello World

ASCII85

用五个可打印字符表示四个字节，比十六进制和 Base64 更紧凑。

<~87cURD]i,"Ebo7~> → Hello World

Base85（RFC 1924 / Git）

以 85 种字符紧凑地表示二进制数据；RFC 1924 与 Git 使用的字母表不同于 ASCII85。

NM&qnZy;B1a%^M → Hello World

Base91

用 91 种可打印字符表示二进制数据，通过可变长度的位分组提高编码密度。

fPNKd → test

Hex 十六进制

用十六进制数字表示数据，每两个数字对应一个字节，常见于文件内容和字节码的展示。

48 65 6c 6c 6f → Hello

URL Percent-Encoding

把字节写成百分号加两位十六进制数，让文字和特殊字符能在网址中传递。

Hello%2520World → Hello%20World → Hello World

HTML Entity

用字符名称或数字编号表示文字，避免尖括号等字符被当作网页标签。

&#72;&#105; → Hi

Binary 二进制字符码

用 0 和 1 表示数值，再通过字符编码把这些数值与文字对应起来。

01001000 01101001 → Hi

Octal 八进制字符码

用 0–7 表示数值；在字符码谜题中，这些数值对应文字的编码。

110 145 154 154 157 → Hello

Decimal 十进制字符码

把文字的字符码写成十进制数字，是数字与文字之间最直观的转换之一。

72 105 → Hi

Unicode / Hex Escape

用反斜杠和十六进制数字表示字符，常见于程序代码与字符串中的字符转义。

\u0048\u0069 → Hi

A1Z26

按字母在字母表中的位置编号：A 为 1、B 为 2，依此类推到 Z 为 26。

8 5 12 12 15 → HELLO

Bacon Cipher

把字母换成五位 A/B 组合，再将两类符号藏入字体、大小写等细微差别中。

aabbb aabaa ababb ababb abbba → HELLO

Morse 摩尔斯电码

用长短两种信号的组合表示字母和数字，既可通过电报码传递，也可藏在声音或闪光中。

.... .. / - .... . .-. . → HI THERE

Polybius 5×5

把字母放入方阵，以行号和列号代替字母，将文字转换为坐标。

23 15 31 31 34 → HELLO

ADFGX

先用 A、D、F、G、X 表示字母的方阵坐标，再通过列换位打乱顺序，结合替换与换位两种思路。

DF AX FA FA FG → HELLO

Tap Code 敲击码

用两组敲击的次数表示字母在方阵中的行列位置，让文字能通过敲击声传递。

xx xxx x xxxxx → HE

Atbash

把字母表首尾互换：A↔Z、B↔Y。应用两次就会回到原文。

Svool → Hello

Reverse 文本反转

把文字从末尾倒写到开头，是谜题中常见的隐藏信息方式。

dlroW olleH → Hello World
密码（密钥模式专用） 11 项

Affine

把字母编号后进行乘法与加法运算，生成一套由两个数决定的替换字母表。

IHHWVCSWFRCP → AFFINECIPHER（5, 8）

Vigenère

用循环关键词决定每个字母的移位量，让同一个明文字母在不同位置变成不同密文。

LXFOPVEFRNHR → ATTACKATDAWN（LEMON）

Beaufort

用循环关键词的字母编号减去明文字母编号得到密文，加密和解密采用同一种运算。

Porta

由关键词选择 13 组互反替换表，字母表前后两半彼此替换，加密和解密使用同一套规则。

列移位

把文字逐行写入表格，再按密钥指定的顺序逐列读出，只改变字符顺序。

Nihilist

先用带密钥的 Polybius 方阵把字母变成坐标数，再与循环关键词的坐标数相加。

Playfair

用一个密钥方阵成对替换字母，根据两字母在方阵中的行、列或矩形关系完成加密。

二方密码

用两个密钥方阵成对处理字母，通过字母位置形成的矩形关系完成替换。

三方密码

用三个密钥方阵交织字母坐标，把两个明文字母变成三个密文字母，并引入随机位置。

四方密码

把两个标准方阵与两个密钥方阵排成四格，通过交叉行列坐标成对替换字母。

Hill

把一组字母看作向量，用密钥矩阵进行模运算，让每个密文字母由多个明文字母共同决定。

延伸阅读：American Cryptogram Association

密码（无需提供密钥） 3 项

Caesar / ROT13

把字母表循环平移固定的位置；ROT13 是平移 13 位的特例，应用两次即可还原。

Uryyb Jbeyq → Hello World

Rail Fence 栅栏密码

把文字沿几行之间的之字形轨迹写下，再逐行读出，以打乱字符的顺序。

WECRLTEERDSOEEFEAOCAIVDEN → WEAREDISCOVEREDFLEEATONCE（3 栏）

Keyboard Shift 键盘移位

把字符替换成键盘上相邻位置的字符，像是整段文字都把手放偏了位置。

Jr;;p → Hello（左移 1 键）；Asdfgh → Qwerty（上移 1 行）

ACG Name

动漫、漫画与游戏中的角色名也能成为谜题线索，罗马字拼写、别名和姓名拆分都可能藏着提示。
