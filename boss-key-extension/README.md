# 老板键浏览器助手

普通网页没有切换任意标签页、最小化窗口或退出浏览器的权限。此 Chrome / Edge 扩展为项目提供这些动作，不读取网页内容、网址或浏览历史，不访问网络。

## 安装

1. 从 [GitHub 仓库下载助手](https://raw.githubusercontent.com/WinyAndME/WinyAndME.github.io/master/releases/boss-key-extension.zip) 并解压。打开 Chrome 的 `chrome://extensions` 或 Edge 的 `edge://extensions`。
2. 打开「开发者模式」，选择「加载已解压的扩展程序」。
3. 选择本 README 所在的 `boss-key-extension` 文件夹，然后刷新游戏网页。
4. 在网站「设置 → 老板键」确认显示「浏览器助手已连接」。

支持正式站点 `https://winyandme.github.io/` 和 localhost / 127.0.0.1 开发服务器。其他部署域名须修改 manifest 的 matches 和 background.js 的来源检查后重新加载扩展。文件方式打开网页不受支持。

## 使用

小游戏页面的音乐播放栏中间点击「老板键」，或按默认 `Alt + B`。设置中可更改组合键和动作，独立于外观设置自动保存。快捷键在游戏页面获得焦点时生效；设置对话框或输入框内不会触发。浏览器/操作系统保留的组合键无法覆盖。

- 切换网页：激活最近使用的其他标签页，必要时切换到其窗口；没有其他标签页时保留已切换的站内首页。
- 最小化：最小化当前浏览器窗口。
- 关闭网页：关闭当前游戏标签页。
- 关闭浏览器：关闭当前配置的所有普通浏览器窗口，包括其中其他标签页。不能保证结束后台浏览器进程，也不会退出其他配置或其他浏览器。

所有动作都会先暂停游戏、切到站内首页并暂停页面音视频。没有扩展时也能完成这一步，并尝试关闭当前标签页（浏览器可能拒绝）；不会假装已执行切换或最小化。

关闭动作可能丢失未保存的数据，游戏没有跨关闭恢复功能。扩展仅响应真实点击和键盘输入。安装扩展是可选步骤，项目不会自动安装或修改浏览器配置。
