关于本站

📢 更新公告

这是一个特别的家庭网站。

从不可能，变成1000行代码，也许只需要灵机一动呢。

本站主体采用纯 前端 实现，静态文件托管在 GitHub Pages；在线音乐功能会由访问者的浏览器直接请求第三方音乐服务，本站不设自有后端或账号系统。

原本的计划是购买域名，这样网址能再短而好记一点，叫winy.online之类的。一年也就需要几十块钱。但是考虑到目前网站还处于展示站阶段，没有什么数据存储和复杂交互，以目前的技术力买域名还是有点小题大做了。

考虑到个人隐私问题，真实姓名和正脸照片在发布版被隐去。完整版保存在本地，并未发布到互联网。

由于前端开发 100% 自学完成，界面设计有诸多不尽人意之处，甚至可能会有奇妙的BUG，敬请谅解。

底部音乐栏支持本地曲目以及在线搜索、播放列表、专辑封面、实时歌词、历史记录和收藏。在线音乐的搜索结果、封面、歌词与播放地址由 GD音乐台及其上游内容来源提供，本站不主张拥有这些内容的版权。

音乐数据说明：播放历史、收藏、排序和播放模式等偏好仅保存在当前浏览器的本地存储中，不会同步至本站服务器；浏览器仍会直接连接第三方服务，其可用性、数据处理和内容权利由相应服务及权利人负责。清除本站浏览器数据即可移除这些本地记录。

其余的功能就请自行探索吧！

感谢访问，希望这个简单的网站能留下温暖和美好的回忆。

权限许可：本站一般原创代码采用 MIT 许可证；BOSS 对决、Wordle 长单词模式及鲜蔬杯工具中心仅许可非商业使用；原创文字与图片保留所有权；第三方代码、API 数据及媒体遵循其各自的许可与权利声明。具体以本站的 许可说明与第三方及内容声明为准。
